# Fundraising OS — Instructions for Claude Code

Before making any change in this repository, read
`docs/FUNDRAISING_OS_PRINCIPLES.md` and treat it as the governing product and
engineering guidance for this project.

Before implementing, identify whether the current task conflicts with
anything in that document, and surface the conflict instead of silently
picking a side.

Never assume tests passed, deployment succeeded, or the current state of
staging or production — verify, or say the fact is unverified.
